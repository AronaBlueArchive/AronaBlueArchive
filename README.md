<summary><b>计数器是怎么运作的？</b>（点开看看）</summary>

互动版主页里有一台真正会动的草莓牛奶计数器：

- 点击「给阿罗娜一杯」，杯数 `+1`，还会掉落草莓和爱心；
- 记录保存在浏览器的 `localStorage` 里，刷新页面也不会消失；
- 每天会自动重置「今日已喝」，累计杯数会一直保留；
- 每满 10 杯会触发一次小小的里程碑庆祝。

数据只留在访问者的浏览器里，不会上传到任何地方。
